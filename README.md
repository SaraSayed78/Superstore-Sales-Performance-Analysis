# Superstore Sales & Profitability Analysis

## 📊 Project Overview
An end-to-end retail analytics and business intelligence solution designed to analyze sales performance, regional profitability, and customer segmentation using Advanced Excel. 

## 🛠️ Tools & Technologies Used
* **Advanced Excel:** Data Modeling, Pivot Tables, Slicers, Timeline Filters, and Advanced Formulas (VLOOKUP, INDEX/MATCH).
* **Business Intelligence & Visualization:** Interactive Dashboard featuring 12 customized charts and KPI cards.
* **Automation & Simulation:** Goal Seek analysis and macro/VBA automation for sales forecasting.

## 📈 Key Features & Dashboard Components
* **Dynamic Interactivity:** Integrated Slicers and timelines allowing stakeholders to filter data seamlessly by region, category, and date.
* **Profitability Insights:** Detailed breakdown of loss-making sub-categories and high-performing product lines.
* **Visual Storytelling:** Clean layout and professional color coding optimized for executive presentation.

## 📂 Project Contents in this Repository
1. **`Superstore_Dashboard.xlsm`**: The complete interactive Excel workbook containing raw data, cleaned tables, and the dynamic dashboard.
2. **`Superstore_Dashboard_Report.pdf`**: High-resolution PDF export of the final dashboard.
3. **`Video_Walkthrough.mp4`**: A recorded screen walkthrough demonstrating the dashboard functionality and workflow.
